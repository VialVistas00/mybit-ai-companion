# 固件说明

## 当前固件

```
MicroPython 1.13.0
npython with ESP32
v1.06.5 on 2024-07-31
```

`npython` 是厂商（杭州纳茵特 RobotEdu）在 MicroPython 上的定制固件，封装了板载外设。

## 关键 API 速查

```python
from npython import *

# 显示
oled.print(x, y, text, clr)      # x=1~18列, y=1~5行, clr=1清行
oled.show()
oled.pixel/line/circle/rect/fill/fill_rect/fill_circle

# 传感器
aht20.read_temp()                # 温度，首次可能 ETIMEDOUT
aht20.read_hum()                 # 湿度
light.read()                     # 光照 0~4095
sound.read()                     # 注意：这块板恒为 0，麦克风走 I2S

# 输出
led.on() / led.off()
rgb.write_left(r, g, b) / rgb.write_right(r, g, b)
beep.time(freq)                  # 阻塞 0.6~1.6 秒
music.pitch(freq, ms)            # 推荐，阻塞 ≈ ms+65ms
music.play(music.JUMP_UP)        # 内置 30 首旋律

# 按键
button.get_a() / button.get_b()  # 返回 0/1

# 音频录制
import audio
audio.recorder_init()
audio.record('x.wav', 3)         # (文件名, 秒数)，最长 3 秒
audio.recorder_deinit()

# 网络
wifi.connect(ssid, pwd)          # 返回 IP
wifi.enable_AP(ssid, pwd, timeout)
wifi.disable_AP()

# 时钟
from machine import RTC
RTC().datetime((年,月,日,星期,时,分,秒,子秒))
import ntptime; ntptime.settime()

# 外设
UART(1, 9600, rx=PINS[0], tx=PINS[1])   # 语音合成模块
I2C / ADC / Pin / PWM / Servo / NeoPixel / Speaker / MQTTClient
```

## 固件升级注意事项

**不要**把 5.8MB 的 `firmware.bin` 从 `0x0` 直接烧：

```bash
# ❌ 错误做法，会破坏引导区导致无限重启
esptool --port COM3 write_flash 0x0 firmware.bin
```

正确做法：

1. 用板子自带的编程工具（信息科技实验板编程工具 V1.32S）里的固件升级功能
2. 或者先确认分区表，烧到 `factory` 分区（`0x010000`）

**升级前必须全片备份**：

```bash
esptool --port COM3 --baud 460800 read_flash 0x0 0x800000 flash_backup.bin
```

恢复：

```bash
esptool --port COM3 --baud 460800 write_flash 0x0 flash_backup.bin
```

## Python 语法限制

固件是 **Python 3.4 语法子集**，实测：

| 特性 | 支持 |
|---|---|
| f-string `f"{x}"` | ❌ SyntaxError |
| `"%d" % x` | ✅ |
| `"{}".format(x)` | ✅ |
| 类型标注 `def f(a:int)` | ✅ |
| 海象运算符 `:=` | ✅ |
| 类 / 继承 / 生成器 | ✅ |

## 内存

```
堆总量 111 KB，空载可用约 89 KB
单次最大连续分配 40 KB（bytearray 实测）
```

**堆碎片比总量更要命**：录音 3 秒可以，4 秒就 MemoryError，哪怕 `mem_free()` 显示 75KB。长时间运行的程序要定期 `gc.collect()`。

## 内置库

```
urequests  ujson  ntptime  machine  network  socket  ussl
ubinascii  ustruct  uio  array  math  gc
microdot（需自行上传）  audio  music  framebuf
```

注意：**没有** `uhashlib.sha1`（本项目手写了一个纯 Python 实现，见 `pc/srun_client.py`）。

## 出厂 boot.py 的坑

```python
_button_a = machine.Pin(21, machine.Pin.IN)
if _button_a.value() == 1:
    os.remove("/main.py")     # 上电时 A 键按下 -> 删掉程序
```

用 `board/boot_safe.py` 替换掉它。
