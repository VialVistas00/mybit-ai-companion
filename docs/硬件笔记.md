### 关于 sound.read() 恒为 0

`sound` 的实际类型是 `ADC(Pin(37))`。

对比各 ADC 通道（同一时刻读取）：

```
GPIO34  [193, 148, 125]   ✅ 有波动
GPIO35  [208, 206, 209]   ✅ 有波动
GPIO36  [179, 123, 112]   ✅ 有波动
GPIO37  [0, 0, 0]         ❌ 恒为 0  ← sound 用的就是它
GPIO39  [48, 0, 29]       ✅ 有波动
```

**这不代表麦克风坏了。** 这块板的麦克风走 I2S，不用 ADC 通道，所以 `sound.read()` 读 0 是正常的。

要采音频请用 `audio` 模块（见下）。

## 音频

### 录音

```python
import audio
audio.recorder_init()
audio.record('x.wav', 3)      # (文件名, 秒数)，最长 3 秒
audio.recorder_deinit()
```

生成 WAV 规格（实测）：

```
单声道 / 8000 Hz / 16 bit / 3.07 秒 / 49196 字节
```

**注意**：
- 4 秒会 `MemoryError`
- 录音前必须 `gc.collect()` 两次
- 有 **-8567 的直流偏置**，处理音频时必须去均值

### 播放/发声

| API | 阻塞时长 | 用途 |
|---|---|---|
| `beep.time(freq)` | 643 ~ 1644 ms | ❌ 不适合实时 |
| `music.pitch(freq, ms)` | ≈ ms + 65 ms | ✅ 短音效 |
| `music.play(melody)` | 0.5 ~ 3 秒 | 非实时场景 |

`music` 内置 30 首旋律：

```
BADDY BA_DING BIRTHDAY BLUES CAI_YUN_ZHUI_YUE CHASE DADADADUM
DONG_FANG_HONG ENTERTAINER FUNERAL FUNK GE_CHANG_ZU_GUO
JUMP_DOWN JUMP_UP MO_LI_HUA NYAN ODE POWER_DOWN POWER_UP
PRELUDE PUNCHLINE PYTHON RINGTONE TEST WAWAWAWAA WEDDING
YI_MENG_SHAN_XIAO_DIAO ZOU_JIN_XIN_SHI_DAI
```

### 语音合成（UART1）

`UART(1, 9600, rx=PINS[0], tx=PINS[1])`

初始化（UTF-8 模式）：
```python
uart1.write(b"\x7e\x00\x0a\x01\x00\x03\x03\xef\x01\x06\x07\xef")
```

帧格式：
```
7E | 帧长(2B大端) | 01 00 03 | 03 E8 | 数据长(1B) | 文本(UTF-8) | 校验(1B) | EF
                   ↑固定头   ↑命令字   ↑≤255字节     ↑累加和%256
```

单帧文本编码后不能超过 255 字节，需要分句。

## 显示（SSD1306 128×64）

```python
oled.print(x, y, text, clr)     # x=1~18 列，y=1~5 行，clr=1 清行
oled.show()                     # 文本外都要手动 show
oled.pixel/line/circle/rect/fill/fill_rect/fill_circle
```

坐标系：x 0~127，y 0~63。`print` 的 y=1~5 对应像素 0/12/24/36/48 附近。

## 按键

```python
button.get_a()    # A 键，返回 0/1
button.get_b()    # B 键
```

**重要**：A 键对应 GPIO21，出厂 `boot.py` 会检查它，上电时若为高电平就删除 `/main.py`。务必换成项目的 `boot_safe.py`。

## GPIO

| 名称 | 说明 |
|---|---|
| pin0 / pin1 | 支持 digital + analog（也用作 UART1 的 rx/tx） |
| pin2 | 模拟输入（作业里读光照用） |
| pin6/9/5/13/3/12/7 | 数字输出（驱动风扇、加热、继电器等） |
| pin4/pin5/pin10~pin20 | 见 `npython` 导出对象 |

## 串口（CH9102）

```
COM3 @ 115200, 8N1, 无流控
```

**注意 DTR/RTS 与 ESP32 自动下载电路的关系**：RTS→EN，DTR→IO0。两者都保持高电平才是正常运行态；拉低 RTS 会让板子一直复位。

## 固件升级

**刷之前必须全片备份**：

```bash
esptool --port COM3 --baud 460800 read_flash 0x0 0x800000 flash_backup.bin
```

**不要**把 5.8MB 的 `firmware.bin` 从 `0x0` 直接烧——那不是完整整片镜像，会覆盖引导区导致无限重启（报 `invalid header`）。

分区表（`0x8000`）：

```
nvs       0x009000   24 KB
phy_init  0x00f000    4 KB
factory   0x010000  1.7 MB   ← 应用固件
vfs       0x200000    2 MB   ← 文件系统（程序都在这）
```

恢复：`esptool write_flash 0x0 flash_backup.bin`
