## 二、开发板实测档案（真机读出来的）

| 项目 | 实测值 |
|---|---|
| 串口 | `COM3` = `USB-Enhanced-SERIAL CH9102`（VID_1A86 / PID_55D4），115200 8N1 |
| 固件 | MicroPython **1.13.0**，`npython with ESP32`，版本 **v1.06.5 (2024-07-31)** |
| CPU / Flash | 240 MHz / 8 MB Flash（文件系统 2 MB，512×4 KB 块） |
| 可用 RAM | 空载 60.7 KB；载入 microdot 后 44.8 KB |
| MAC | `00:00:00:00:00:00` |
| I2C 总线 | `0x38` = AHT20 温湿度，`0x3c` = SSD1306 OLED 128×64 |
| OLED | `<class 'OLED'>`，宽 128 |
| 传感器实测 | 光照 **272~289**、声音 **21~362**、温度 **26.6→29.6 ℃**、湿度 **24.8~29.3 %** |
| WiFi | STA 可开、可扫到周边 2.4G 热点；`enable_AP()` 建热点成功 |
| 板载文件 | `boot.py`(316 B)、`main.py`、`microdot.py`(46 368 B)、`temphtml.py`(3 517 B) |
| 固件 API | `oled / button / aht20 / light / sound / led / rgb / beep / wifi / mqtt(MQTTClient) / OLED / Speaker / NeoPixel / PINS / gequ / music` |

### 两个必须先知道的坑

1. **`boot.py` 会在上电时删掉你的程序。**
   源码：`_button_a = Pin(21); if _button_a.value()==1: os.remove("/main.py")`
   即上电瞬间 A 键处于按下/高电平，`main.py` 会被直接删除。板子"程序莫名消失"就是它干的。
2. **第一次读 AHT20 会 `ETIMEDOUT`。**
   上电后首次 `read_temp()` 需要约 1 次失败唤醒，第二次起就稳定（实测第二次即返回 26.63 ℃）。

## 六、附：本次生成的工具

`开发板\mybit.py` —— 不依赖 ampy/mpremote 的 MYBIT 串口客户端（走 MicroPython raw-REPL）：

```python
from mybit import MyBit
d = MyBit("COM3")
d.ls()                                   # 列板载文件
d.exec("print(1+1)")                     # 在板上执行
d.put("microdot.py", "microdot.py")      # 上传
d.get("main.py", "backup_main.py")       # 下载
d.reset()                                # Ctrl-D 软重启
d.close()
```

配套脚本：

- `flash_clock.py`（本次用）：把作业1 烧成 `main.py` 并自动验证
- `flash_microdot.py`：上传 microdot 全家桶并在板上自检
- `_board_backup\`：你板子原始 `boot.py` / `main.py` 的备份，随时可还原
